# 工具集 Toolkit

黑白极简的小工具合集,纯静态单文件 HTML,文件只在本机浏览器处理。

| 工具 | 文件 |
| --- | --- |
| 工具集首页 | `index.html` |
| 盖盖(盖章 / 签名) | `gaigai.html` |
| PDF 工具箱(合并、拆分、删页、旋转、页码、转图片、图片转 PDF、Word 转 PDF、压缩) | `pdf-tools.html` |
| PDF 编辑 | `pdf-editor.html` |
| MD 转换(Markdown → Word) | `md-converter.html` |
| 发票合并 | `invoice-merge.html` |
| 金额大写 / 汇总 | `rmb-upper.html` |
| 含税换算 | `tax-calc.html` |

## iPhone 添加到主屏幕
Safari 打开站点 → 分享 → 添加到主屏幕。每个工具页都有各自的图标(`icons/`),也可以只添加首页。

## 部署
GitHub Pages:Settings → Pages → Branch 选 `main` / `/ (root)`。
